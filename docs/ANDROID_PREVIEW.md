# Android 0.1.3 ARM64 多端口侧载预览

## 安装包

- PortLink-0.1.3-Android-arm64-preview.apk，Release优化构建，arm64-v8a，20,297,837字节。适用于大多数64位Android手机，最低Android7.0/API24，targetSdk36。
- 版本名0.1.3，ARM64分ABI版本码2004，高于旧0.1.0包2001；本机预览证书与旧包一致。仍使用Android Debug证书签名，**仅供侧载预览，不是正式发布签名**。签名私钥不上传，证书是APK公开信息。
- SHA256：5654fdfb8f8ff619a5a8bd07f08dcc4bb61a780b16f27c54715c1b7d6d81e7e4。

## 与Mac/Windows一致的业务功能

- 多台SSH服务器保存、编辑、删除、默认服务器、系统安全存储密码及启动默认连接；首次主机指纹主动核对，变化阻断。
- 每台服务器最多32条转发规则：名称、启用/删除、自定义本机IPv4监听地址与端口、自定义SSH侧目标域名/IP和端口；所有规则共用一条SSH会话。
- 逐规则显示可用/本地绑定失败/远端不可达，某条失败不影响其他规则；逐规则复制本地地址与打开HTTP（仅目标确实提供HTTP时）。
- 默认仍手机127.0.0.1:3080 → SSH服务器127.0.0.1:3080；地址/端口均可按规则改。手机浏览器访问的是手机自身本地规则地址，不是Mac。
- 默认loopback仅本机；显式绑定0.0.0.0或其他本机IP可能让局域网设备无需SSH凭据访问该监听，请仅在明确需要时使用，远端服务自身仍须认证。

## Android专有运行方式

Android13+须允许通知才能开始会话；通知已改成“本次多端口SSH转发”，打开应用查看规则，应用或通知“停止转发”会停止全部监听。无开机自启、无wakelock/电池豁免、无强杀后自动复活，不承诺长期后台/锁屏保活。

安装APK时按系统流程允许此次安装来源，不关闭系统安全保护。尽量保留原安装直接更新；卸载会删除应用配置和安全凭据。密码在应用里输入，不发聊天。首次连接通过管理员/服务器控制台核对完整SHA256指纹，不确定就拒绝。

旧schema1配置可迁移为默认规则，新保存写schema2；旧应用不能读v2，升级前保留配置备份，不回退旧程序覆盖。
