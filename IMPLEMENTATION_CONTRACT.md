# PortLink implementation contract

Single Flutter application: macOS Apple Silicon and Windows desktop first; Android user-started foreground session, no boot start. Mac and Windows share up to32 configurable local IPv4 address/port -> SSH-side target host/port rules on one selected SSH connection; default and v1 migration remain127.0.0.1:3080 -> server127.0.0.1:3080. Nonloopback binding is explicit and warns about LAN exposure. No cloud, no terminal, no telemetry.

## Core public contract (implement these paths/classes)
- lib/core/server_profile.dart: immutable ServerProfile({required String id, required String name, required String host, int sshPort=22, required String username}); fields same names; toJson(), factory fromJson(Map<String,dynamic>); String? validate() returning Chinese validation error or null. IDs UUID supplied by controller. No password in model.
- lib/core/tunnel_status.dart: enum TunnelPhase {idle, connecting, verifyingHost, ready, reconnecting, targetUnavailable, failed}; immutable TunnelStatus({required TunnelPhase phase, String? profileId, String? message, int retryAttempt=0}); fields; bool get isActive (connecting/verifyingHost/ready/reconnecting/targetUnavailable); bool get isConnected (ready/targetUnavailable).
- lib/core/host_trust.dart: immutable HostTrustRequest({required String host, required int port, required String keyType, required String fingerprint}); typedef HostTrustPrompt = Future<bool> Function(HostTrustRequest request); host-key changed must fail, never prompt replacement as ordinary new trust.
- lib/data/profile_repository.dart: abstract interface class ProfileRepository {Future<ProfileSnapshot> load(); Future<void> save(ProfileSnapshot snapshot);}; immutable ProfileSnapshot({List<ServerProfile> profiles=const [], String? defaultProfileId}); JsonProfileRepository(String filePath), atomic writes+backup. No Flutter dependency in pure repositories. Read schemaVersion1/2, write2; only v1 can omit rules for legacy migration, v2 missing rules fails closed. Freeze rule lists in persisted/running snapshots; validate limits and no duplicate IDs.
- lib/data/secret_store.dart: abstract interface class SecretStore {Future<String?> readPassword(String profileId); Future<void> writePassword(String profileId,String password); Future<void> deletePassword(String profileId);}; class SecureSecretStore implements SecretStore (flutter_secure_storage). Controller handles errors (never fallback plaintext).
- lib/data/host_trust_store.dart: abstract interface class HostTrustStore {Future<String?> readFingerprint(String host,int port,String keyType); Future<void> trust(String host,int port,String keyType,String fingerprint);}; JsonHostTrustStore(String filePath), atomic write. Trust key must host+port, changing algorithm cannot silently bypass host-key changed detection; readFingerprint should distinguish conflicting stored algorithm via thrown HostKeyChangedException or equivalent.
- lib/core/tunnel_engine.dart: abstract interface class TunnelEngine {Stream<TunnelStatus> get statuses; TunnelStatus get status; Future<void> connect(ServerProfile profile,String password,{required HostTrustPrompt onTrustHost}); Future<void> disconnect(); Future<void> dispose();}; class SshTunnelEngine({required HostTrustStore trustStore,...optional test timing injection}); use dartssh2; fixed loopback binding. Generation tokens cancel/reject stale callbacks; only one listener and retry task; connect returns after initial attempt (no endless retries awaited). Auto retry transient network only with bounded exponential backoff+jitter. Auth/trust/bind errors fail without automatic retries. Ready requires auth+listener+SSH target TCP probe. targetUnavailable remains tunnel listening, periodically re-probe. Health ping must have timeout, application target probe through SSH not just local accept. Copies support half-close/backpressure, bounded operations; clean failed accepted channels; disconnect closes listeners/sockets/timers. Explicit handshake/auth/connect/probe timeout. First host prompt only for unknown; changed hard-stop. Do not log secrets or enable SSH traces.

## Lead AppController UI contract
lib/app_controller.dart: class AppController extends ChangeNotifier.
Getters: bool initialized; bool busy; List<ServerProfile> profiles; String? defaultProfileId; ServerProfile? activeProfile; TunnelStatus tunnelStatus; String? errorMessage; HostTrustRequest? pendingTrust;
Methods: Future<void> initialize(); Future<void> saveProfile({String? id,required String name,required String host,required int sshPort,required String username,String? password,required bool makeDefault}); Future<void> deleteProfile(String id); Future<void> setDefault(String id); Future<void> connectProfile(String id); Future<void> disconnect(); Future<void> shutdown(); void answerHostTrust(bool accept); void clearError();
New profile requires nonempty password. Edit blank password means retain existing; never display existing password. If editing active connection, disconnect+restart only after save success. Set default DOES NOT switch connection. If deleting default choose first remaining; deleting active disconnect. First load autoconnect default if saved. busy gates config mutation/connect switch. Errors surfaced via errorMessage; UI catches errors if any without crashing.

## UI entry
lib/ui/portlink_app.dart: class PortLinkApp extends StatelessWidget {const PortLinkApp({super.key,required AppController controller});}. App theme light/dark system, Chinese readable simple elegant compact desktop and responsive mobile. Root owns home window; initialization performed by main, not UI. Listen pendingTrust and show one non-dismissible explicit dialog (or overlay) with host/port/keyType/SHA256 and instruction verify via trusted channel. Must not autoaccept. UI renders errors inline, no accumulating snackbars; supports add/edit/delete confirmation/default selector/connect/stop/copy local address, external open via url_launcher only after user action. Treat target protocol unspecified: button says open HTTP page, do not imply generic TCP is always HTTP. No dependencies on desktop plugin.
